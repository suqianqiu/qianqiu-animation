# 1.6.8 更新与验证记录（2026-11-13）

修复北斗神拳等 HLS 清单存在 `METHOD=NONE` 时跳过已知广告指纹检测的问题。该标记代表后续分片不加密；真正的 AES 加密或不支持的清单仍不擅自改写。

## 本版优化

- 完整已复核广告序列可在相邻分片中匹配，不再要求广告独占整个 discontinuity 区间；匹配时核对完整时长与内容 SHA-256。
- 指纹探测最多并发3个、24个唯一请求、总预算12秒；先确认首片，才预取剩余片段，结束时取消任务。
- 已确认广告首片但后续验证失败时，明确返回未完成，避免当作已验证内容放行。预算限制仍可能导致部分新样本无法识别，不承诺未知广告实时清除。
- 在线播放、新下载及旧缓存复检共用规则；旧缓存合并时间映射。补充一组已完整复核的五分片广告序列，没有新增整线路封禁。
