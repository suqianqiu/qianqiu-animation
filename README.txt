1.3.0 本地缓存与后台下载
- 默认开启后台自动下载当前播放集；首页、播放器均可打开下载管理。
- HLS 点播先缓存最多3个资源，再通过仅本机可访问的HTTP服务共用磁盘片段；同一片段不重复下载。
- 退出播放器后前台服务继续下载，通知栏显示状态；应用被强行停止或设备重启后需打开应用并继续任务。
- 下载管理提供片段百分比、已下载字节、速度、暂停、继续/重试、删除与离线播放。
- 默认4GB上限，可选1/4/8/16GB，系统剩余不足512MB时停止写入并显示错误，不自动删除已下载内容。
- 完整下载的HLS和MP4可离线播放；HLS断点保留完整片段，未完成的单片会重下。MP4后台下载为整文件，暂停后该文件重新下载；未完成MP4仍在线播放。
- 支持普通HLS VOD、多码率列表首条线路、AES-128密钥和fMP4初始化片段；直播、字节范围HLS、独立外部音轨与其他加密格式暂不支持缓存，会提示并尝试在线播放。
- 默认自动下载只针对当前集；不会自动下载整部或下一集。关闭自动下载不删除已有任务，暂停已有任务请使用“全部暂停”。
- 测试源服务关闭后已在AM9 PRO验证本地HLS出画面与进度推进；这不代表所有来源长期可用或卡顿完全消失。
